# ふわふわ（FuwaFuwa）- 本地衣柜管理应用 ୨୧

> “在廉价的生活里做着轻飘飘的少女梦”

「ふわふわ」是一款服务于Lolita爱好者的个人衣物数字化归档 Android 应用。

---

## ୨୧ 核心功能与四大 Tab 架构 (v2.0)

1. **Tab 1: 【Lolita ＆ 小物】(`LolitaScreen`)**：
   - 顶部书签栏平滑切换：【洋装裙装】与【搭配小物】各自独立的双列拍立得照片流。
   - 洋装与饰品均支持**全款现货**与**定金尾款制**工期跟踪（待补款金平糖金呼吸徽章“已等 X 天”，已出货“工期 X 天”）。
   - 右下角粉色小缎带 FAB 按钮，一键选择【录入洋装】或【录入小物】。

2. **Tab 2: 【地球人衣柜】(`EarthScreen`)**：
   - 独立常服衣柜，拥有完整的上衣、下装、外套、连衣裙、鞋、袜、帽子、包、伞等子类目。
   - **双排胶囊交集联动筛选**：第一排服装子类目，第二排春夏秋冬季节，支持双重筛选（如“春季-上衣”、“冬季-连衣裙”）与小缎带一键重置。

3. **Tab 3: 全新【心愿单】(`WishlistScreen`)**：
   - 专属种草管理：记录心动单品名称、店家品牌、预算金额、预计贩售月份（年-月）。
   - **少女感心动等级**：`非入不可 ♡` | `很心动 ୨୧` | `还在观望 ~`。
   - 支持 **【转入衣柜 ୨୧】**（预填数据打开录入表单，入库后自动移出心愿单）与 **【拔草（不喜欢了）】** 一键删除。

4. **Tab 4: 【记账看板】(`FinanceScreen`)**：
   - 顶部资产总额与待补尾款预警看板。
   - 支出分类占比进度条（Lolita 洋装 vs 地球人常服 vs 搭配饰品）。
   - 选中具体月份时，顶部高亮呈现月度总支出与扣款笔数卡片；明细流水一律采用柔和的 `¥278` 正数呈现（绝无负号）。

5. **纯本地离线与视觉规范**：
   - 绝无外部云端依赖与鉴权，基于本地 SQLite 关系型存储。
   - 拍照与相册选取自动执行 1080p 硬件压缩，存入手机私有沙盒。
   - 全套生成芭蕾舞鞋粉底色 + 白色小缎带（`୨୧`）高清手机桌面图标。
   - 拍立得相纸卡片底部加宽留白，搭配弹性按压缩放反馈与小缎带呼吸微动效。

## ୨୧ 实机安装与自动化云打包指南

本项目已内置 GitHub Actions 自动化编译脚本：
1. 将项目源码上传至你的私密 GitHub 仓库；
2. GitHub 云端电脑将在 2~3 分钟内自动生成安装包；
3. 在 GitHub 网页的 **Actions** 页面即可直接下载 `FuwaFuwa-Release-APK`，传输到手机点击安装！
